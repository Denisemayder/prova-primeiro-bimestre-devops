# Prova Primeiro Bimestre - DevOps 2026.2

**Aluna:** Denise Maider Batista de Macedo

## Descrição

Projeto desenvolvido para a prova do primeiro bimestre da disciplina de DevOps.

O projeto consiste em uma API de Reservas utilizando Node.js, Express e PostgreSQL, com conteinerização utilizando Docker e Docker Compose e provisionamento de infraestrutura AWS utilizando Terraform.

## Tecnologias

- Node.js
- Express
- PostgreSQL
- Docker
- Docker Compose
- Terraform
- AWS
- Kiro
